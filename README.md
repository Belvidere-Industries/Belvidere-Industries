# Belvidere Industries

Current work centers on a high-mix custom manufacturing implementation of Acumatica, including Product Configurator, multi-level BOM and routing structures, and mixed in-house and outsourced production.

We're also exploring agentic development techniques for Acumatica implementation and customization: coding agents, reusable skills, authoritative documentation, runtime testing, and structured acceptance. The practical goal is to make complex implementation work more effective, supportable, and easier to share across a team.

Useful pieces of that work beyond our specific implementation are being contributed back to the Acumatica community.
